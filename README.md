# PicGrab

Windows 11 標準の .NET Framework を使用する JPEG 写真ビューアーです。

## ビルド

Windows 11 で `build.bat` をダブルクリックするか、コマンドプロンプトで実行します。Visual Studio、SDK、追加パッケージは不要です。`dist\PicGrab.exe` が作成されます。

## 使い方

1. `PicGrab.exe` を起動し、「フォルダーを選択」で JPEG ファイルの入ったフォルダーを選ぶか、隣のアドレスバーにフォルダーのパスを入力して Enter を押します。対象はそのフォルダー直下の `.jpg` と `.jpeg` です。
2. 左の写真をクリックすると、最後にクリックした写真が右に表示されます。写真左上のチェックボックスで複数選択できます。チェックボックスをクリックした写真もプレビューされます。左ペインにフォーカスがあるときは、矢印キーで写真を移動してプレビューし、スペースキーでチェックを切り替えられます。最初の矢印キーで先頭の写真を表示します。
3. 左の写真上からドラッグすると、**チェックした写真すべて**をファイルとして渡します。プレビュー中の写真はチェックされていなければ含まれません。チェックがない場合はドラッグしません。ブラウザーのファイルアップロード欄やエクスプローラーにドロップできます。移動またはコピーはドロップ先と Ctrl / Shift キーの操作に従います。
4. 「選択」メニューの「すべて選択」で全写真にチェックし、「選択の切り替え」でチェック状態を反転できます。
5. 右のプレビュー上でマウスホイールを回すと、カーソル位置を中心に拡大・縮小できます。左ボタンでドラッグすると表示位置を移動できます。別の写真を選ぶと倍率と表示位置はリセットされます。同じ写真を再度選んだ場合は表示状態を維持します。

元画像そのものを渡すため、移動先での操作によって元ファイルが移動される場合があります。フォルダーの内容を外部で変更した場合はフォルダーを選び直してください。
